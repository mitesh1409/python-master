# Colon `:`

The colon (:) indicates a code block is about to begin.  
And a code block in Python ends when the indentation ends.  

Think of the colon and indentation as going together:  
you can’t have one without the other.

FYI: the  
Python docs  
refer to a  
“code block”  
as a “suite.”

Roses are red,  
violets are blue.  
Don’t forget the colon,  
‘cause Python won’t like you.
