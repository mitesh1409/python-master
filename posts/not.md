# The "not" keyword

- `not` = check if a condition **is not** met
- Useful for validating that something is missing

```python
pantry_items = ["flour", "sugar", "olive oil"]

# Check if "salt" is NOT in our pantry
if "salt" not in pantry_items:
    print(True)
else:
    print(False)
```

**Output:**
```
True
```
