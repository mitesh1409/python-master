# Indexing List Elements

Indexing List elements

positive indexing - left to right, starts with zero.

negative indexing - right to left, starts with -1.

```bash
>>> numbers = [1, 2, 3, 4, 5]
>>>
>>>
>>> numbers[0]
1
>>> numbers[1]
2
>>> numbers[2]
3
>>> numbers[3]
4
>>>
>>>
>>> numbers[-1]
5
>>> numbers[-2]
4
>>> numbers[-3]
3
>>>
```
