# Getting help via BIFs `dir`, `help`

You can use Python's BIFs (Built-In Functions) `dir` & `help` to get help 
on an object/method without leaving your IDE or Jupyter Notebook.  

`dir`  
It gives you a complete list of all the attributes and methods available for an object.  

`help`  
It gives you documentation for the method.  
Its signature, one liner description, description about the parameters etc.
