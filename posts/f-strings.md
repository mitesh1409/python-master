# f-strings

f-strings, short for "formatted string literals".  

An f-string lets you build a string  
without having to rely on the  
troublesome + operator. Instead, you  
embed your variable values into the  
f-string.  

**Variable Interpolation**  
When f-string sees variable names enclosed in curly braces `{}`,  
it gets the value of variables and inserts it into the place where  
variable names are enclosed in curly braces `{}`.

In other words we can embed variables into a string using curly braces `{}`,  
and they will be replaced by their values via **Variable Interpolation** mechanism.
