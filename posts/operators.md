**Division with integers and floats**  

Python supports two different division operators: `/` and `//`.  
In Python 3, `/` will consistently return a float result,  
and `//` is floor division and will consistently return an integer result.  

Floor division is the same as doing `math.floor(numerator/divisor)`,  
which returns the highest integer less than or equal to the result  
of the division operation.  

You can learn more about `math.floor` in the [Python Docs](https://docs.python.org/3/library/math.html#math.floor).
