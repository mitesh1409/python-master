# Testing

Python comes with the build-in `unittest` library, which is modeled on a
similar testing technology originally developed for Java. Although part of the PSL,
`unittest` is not the recommended automated testing tool nowadays, having been
supplanted in many Python programmer’s eyes by `pytest`.

If you are writing code that you hope to deploy to production, then you should be
writing tests for that code, too. When it comes to learning `pytest`, we recommend
[Python Testing with pytest, 2nd Edition](https://pragprog.com/titles/bopytest2/python-testing-with-pytest-second-edition/) by Brian Okken.
