# Constants

When you see  
an uppercase  
variable  
name, think  
“constant.”

Python doesn’t support the notion of constant values, so it’s a convention  
within the Python programming community to use UPPERCASE variable names to  
signal to other programmers that the values are constant (and should not be changed).  

Python doesn’t enforce this naming convention, as it’s not a language rule.
