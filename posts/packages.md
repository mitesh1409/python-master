# Packages

* A collection of modules = Package (also called a library)
* Publicly available and free
* Download it from PyPI (Python Package Index). The Python Package Index (PyPI) is a repository of software for the Python programming language.
* They can be imported and used like modules.

To manage packages into our project we can use "pip" or "uv".  

"uv" is preferred over "pip" as it is modern and very fast.

Use the following command to install packages:  

`python3 -m pip install <package-name>`  
OR  
`uv add <package-name>`

* time
